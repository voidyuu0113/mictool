麥克風、程式聲音與 OBS 路由，一頁搞定

MicTool 適合直播、OBS、Discord、歌回與日常語音。你可以快速切換 Talk / Sing、使用變聲與音效板，還能把指定程式的聲音用 App Loopback 精準混進同一條輸出鏈。

主要特色

把最常用的功能放在前面講清楚，不繞太多字。

Talk / Sing

依用途切換

講話、直播、歌回可以用不同處理鏈，不需要從零重調。

App Loopback

指定程式混音

不是整個系統聲音一起送，而是挑你要的播放器、遊戲或瀏覽器程式。

Voice

變聲與互動

可快速切換多種變聲模式，也能保留一組自訂調整。

Soundboard

音效與快捷鍵

音效板、全域快捷鍵、背景操作與系統匣控制整合在同一套流程裡。

第一次使用

如果你只是想先用起來，照這三步就夠了。

1

選裝置

先設定 Input、Output，必要時再開 Monitor。

2

選模式

講話用 Talk，唱歌用 Sing，需要時再加變聲或音效板。

3

接到 OBS

把 Output 指到虛擬音訊裝置，就能送進 OBS 或其他軟體。
