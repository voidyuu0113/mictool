功能特色

這不是只有做麥克風美化的工具。MicTool 更偏向一個 Windows 桌面上的聲音工作台，讓你把輸入、處理、混音、觸發和輸出放在同一個流程裡。

Talk / Sing

依用途切換人聲鏈

內建 Talk 與 Sing 兩種主要工作模式，適合講話、直播、歌回或需要不同空間感的人聲情境。

App Loopback

指定程式單獨混音

可選擇特定 Windows 程式做 loopback，把伴奏、遊戲、播放器或瀏覽器音訊精準送進輸出鏈，而不是把整個系統聲音全部混進來。

Voice

快速變聲與角色音

提供多種變聲模式與自訂模式，適合互動、角色音、效果聲或日常娛樂用途。

Soundboard

即時音效板

支援多音效匯入、獨立音量調整與播放/暫停切換，也能搭配快捷鍵使用。

Global Hotkeys

背景也能操作

支援鍵盤與滑鼠組合鍵綁定，程式在背景時依然能切換模式、觸發音效或控制聲音輸出。

Tray + OBS

更適合 Windows 桌面流程

支援系統匣最小化與 OBS 常見路由方式，維持常駐又不需要把畫面一直留在桌面上。

第一次使用怎麼開始

如果你只是想先把聲音送進 OBS 或 Discord，不需要一開始就碰所有進階參數。照這個順序做會比較快進入可用狀態。

選好 Input / Output / Monitor

先選麥克風輸入，再選主輸出。如果你想自己監聽，另外設定 Monitor。

切換到 Talk 或 Sing

一般講話建議先從 Talk 開始，唱歌或需要較多空間感時再切到 Sing。

套用 preset 或 Auto Setup

你可以先套用一組 preset，或用 Talk Auto Setup 講幾秒話，讓系統幫你建立一組比較安全的起點。

需要混伴奏時加上 App Loopback

到設定區選擇指定程式，例如播放器、瀏覽器或遊戲，把它單獨混進目前的輸出鏈。

把 Output 接到 OBS 或其他軟體

若要進 OBS，建議把 Output 設成 VB-CABLE 之類的虛擬音訊裝置，再在 OBS 選同一個來源。

為什麼 App Loopback 值得特別提

很多 Windows 聲音工具能做到整體系統聲音 loopback，但能直接挑特定程式、再把它精準混進同一條工作流程的並不多，這正是 MicTool 很有辨識度的地方。

它和整體系統聲音 loopback 有什麼差別？

整體系統聲音會把所有 Windows 聲音一起送出去。App Loopback 則是只抓你指定的程式，控制更細，也比較不容易把不想送出的聲音一起混進去。

適合哪些情境？

伴奏只想送播放器、遊戲只想送某個程式、瀏覽器音訊只想送指定分頁相關程式，這些都很適合用 App Loopback 來做。

GitHub Pages 頁面會連到哪裡下載？
