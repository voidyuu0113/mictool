Windows 上能直接選「特定程式」做 loopback 的桌面工具不多。MicTool 的重點不是只是混系統音，而是讓你有更細的程式級控制。

核心功能

少一點字，多一點可視化。

App Loopback

只混你選的程式聲音，不是整個 Windows 系統音一起進來。

Talk / Sing / Voice

講話、唱歌、變聲各有不同節奏，不必每次都從零開始調。

Soundboard + Hotkeys

音效、快捷鍵、背景操作與系統匣，適合演出中快速切換。

適合這些情境

用情境理解，比參數列表更快。

直播

OBS 路由

把麥克風處理後送進虛擬音訊裝置，再交給 OBS。

語音

Discord / 遊戲

保留麥克風控制，必要時再加上特定程式聲音。

表演

歌回 / 互動

伴奏、音效板、快捷鍵和變聲可以集中管理。

開始使用

第一次上手先照這三步。

選 Input / Output

先設定麥克風和主輸出，需要時再補 Monitor。

選模式與 Loopback

講話用 Talk，唱歌用 Sing，需要混伴奏就加 App Loopback。

送進 OBS 或其他軟體

把輸出指到你要的虛擬裝置或目的地，就能開始使用。
