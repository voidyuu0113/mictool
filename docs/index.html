把聲音流程整理成一個地方

MicTool 把 Talk、Sing、Voice、Soundboard、Hotkeys 與 App Loopback 收進同一套操作介面，讓你更快把聲音整理好，再送進 OBS 或日常語音流程。

更像一個聲音工作台

不是一堆分散小工具，而是一個能把麥克風處理、路由與演出控制放在一起的桌面工作流程。

核心功能

把最常用的即時聲音功能放進同一個流程裡，不需要在多套工具間反覆切換。

Talk / Sing

針對講話與唱歌分開調整，保留即時處理鏈，讓你更快進入可用狀態。

Voice

切換不同變聲模式，搭配現有處理鏈與輸出流程，不用額外重建整套設定。

Soundboard + Hotkeys

支援多音效匯入、個別音量與全域快捷鍵，背景執行時也能直接觸發。

App Loopback

把指定程式的聲音加入你的輸出鏈，不需要把整個系統聲音都一起丟進去。

使用流程

頁面結構以實際操作順序為主，不用先理解所有參數，先把聲音接起來就能開始。

1

選裝置與模式

設定 Input、Output、Monitor，然後在 Talk、Sing 或 Voice 之間切換你現在要用的流程。

2

補上需要的控制

如果有伴奏、遊戲或播放器，就把指定程式聲音一起加進來；如果是演出或實況，再配上 Soundboard 和 Hotkeys。

3

送進 OBS 或語音軟體

整理好的輸出可以直接進 OBS、Discord 或其他 Windows 聲音流程，不必再拆成多套工具接線。

以工作流程為中心

把人聲處理、模式切換、音效與路由整理成一套更容易理解的桌面操作介面。

適合的使用方式

直播人聲整理 OBS 音訊路由 歌回與伴奏 Discord / 遊戲語音 音效板觸發 背景快捷鍵

常見情境

不同使用場景可以直接沿用同一套聲音工作台，不用每次重新拼裝流程。

直播

把麥克風整理後送進 OBS

用 Talk 或 Sing 模式先整理人聲，再決定是否加入程式聲音與音效板，最後送到直播輸出。

語音

日常通話也能維持固定音色

快捷鍵、Monitor 和裝置切換都在同一套介面裡，開會、聊天或遊戲連麥都比較好維護。

演出

把操作集中起來比較不容易手忙腳亂

變聲、模式切換、音效觸發與程式音訊整合都集中管理，現場操作更清楚。
